Static files served by GitHub Pages at https://apps.adaptivepace.com.

  the Accounting Sync for Xero app (client ID only; nothing secret).
- `CNAME` — the custom domain GitHub Pages serves this repo on.
- `.nojekyll` — serve files as-is, without Jekyll processing.
